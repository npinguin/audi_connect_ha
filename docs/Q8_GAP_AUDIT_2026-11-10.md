# Q8 PHEV — cross-layer functional gap audit (2026-11-10)

## Evidence and limits

Evidence: live Audi Connect v2.5.3b5 diagnostic export on HA 2026.11.1, HA restart log, live owner confirmation, GitHub upstream issues #907, #687, #861, #903, #873. No Audi credentials, VIN or precise location stored in this report.

Live owner acceptance: **climate start and stop, door unlock, and flash lights physically work**. Door LOCK physically does NOT work. Therefore do not modify the three working command routes. Audi API cloud/session refresh works, and car data was fresh in the last observed export.

## Engineering acceptance gates

1. Unit + hassfest pass. Existing lock/unlock/climate/flash regression tests pass.
2. No vehicle ID, token, PIN, GPS or raw cloud response in diagnostics/log messages by default.
3. Sensor unique IDs stay stable for Model, Park Time and Position; no extra device.
4. Owner verifies both doors locked in reality before accepting LOCK. An HTTP 200 is insufficient.
5. Clear Model fallback source and Park Time estimate provenance in HA attributes.
6. Avoid launching another exploratory feature/release until these are verified in real HA.
